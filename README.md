# カット記録ツール（cut-boundary-tool）

アニメの動画のカットの境目を機械の候補を見ながら決め、全カットのショット長・サイズ・アングル・BGオンリー・被写体の数を記録して集計・比較するブラウザのツールです。
https://nzanke.github.io/cut-boundary-tool/

動画はパソコンの中だけで処理し、どこにも送りません（ページと部品を読み込むだけで、動画のデータは外に出ません）。

## 使い方
1. パソコンの Chrome で上のページを開く。
2. 「動画を選ぶ」で動画（MKV・MP4・WebM）を選び、「回のID」（例：`madoka-02`）を入れる。
3. 機械が全部のコマを読み、境目の候補を出す。1話で10〜30分ほど（パソコンの速さによる）。途中でタブを閉じない。一度読んだ動画は結果をブラウザに残すので、次に同じ動画を選べばすぐ開く。
4. コマの帯で決める。
   - 緑＝機械がほぼ確実とした境目（最初から境目）。黄＝機械が迷った所。押すと「境目」と「同じカット」が切り替わる。
   - 印のない所も、コマの間を押せば境目を足せる。
   - J／K で次・前の未決の黄へ。1＝境目、2＝同じカット。
   - 境目の行の選択肢で、パートの頭（アバン・OP・Aパート・アイキャッチ・Bパート・ED など）を選ぶ。本編（アバン・Aパート・Bパート）以外は薄く表示し、黄の数にも入れない。
5. 「境目を確定してカットへ」を押す。全カットのショット長が自動で出て、カード（中のコマを大きく、頭と尻を小さく）が並ぶ。カードごとに、サイズ（超ロング・ロング・ミドル・アップ・超アップ・途中で変化）、アングル（水平・アオリ・真下・フカン・真上・ダッチ）、BGオンリー、被写体の数（0〜4以上・群衆）を選ぶ。
6. 集計（平均・中央値のショット長、長さの分布、サイズ・アングル・被写体の数の内訳）はその場で出る。サイズ・アングル・被写体・BGオンリー・秒数の範囲・パートで、カードを絞り込める。
7. 「記録に保存」で、数字・カットの画像・メモを非公開の記録用リポジトリ（例：nzanke/cut-records）に保存する。最初に「設定」で、そのリポジトリだけを選んで Contents を Read and write にした鍵（fine-grained personal access token）を入れる。鍵はブラウザの中にだけ保存し、GitHub 以外には送らない。
8. 「過去の記録」で、回どうし・作品どうし（「作品ごとにまとめる」）の数字を表で比べ、回を開き直して絞り込みもできる。

Claude に演出の分析を頼むときは、境目を決めたあと「Claude 向けに書き出す」でできる `境目_回のID.json` を渡す。

## 記録用リポジトリの中身
- `records/index.json`：回ごとの集計（比較の表に使う）
- `records/<回のID>/record.json`：全カットの範囲（コマ番号）・パート・サイズ・アングル・BGオンリー・被写体の数・メモ
- `records/<回のID>/README.md`：集計とカットの一覧（GitHub でそのまま読める）
- `records/<回のID>/img/NN.jpg`：25カットずつの画像（左に中のコマ、右上に頭、右下に尻）
- `records/<回のID>/boundary.json`：境目を決めたときの全部（機械の候補・押した答え）

アニメの画像を含むので、記録用リポジトリは必ず非公開にしてください。

途中の答えはブラウザ（localStorage）に残るので、閉じても同じ動画を選べば続きから始められます。

## 機械の候補の決め方（nzanke/anime-database の境目ビューアと同じ）
- 今の機械：ffmpeg の scene と同じ値（幅256の明るさの差）が0.15以上で、前の候補から7コマ以上離れたもの。
- TransNetV2：コマごとの切れ目の確率が0.2以上の山。±2コマ以内は同じ境目、3コマ以内の候補は前にまとめる。
- 緑＝前後のコマで TransNetV2 の確率が0.85以上。黄＝それ以外。
- 帯には6コマおきのコマと、候補の前後6コマを1コマずつ並べる。1コマずつ並んでいない所に足した境目は、書き出すときに間で画面が一番大きく変わるコマに合わせる。

## 書き出すファイル
`境目_回のID.json`：`lo`・`hi`（本編の最初と最後のコマ）、`boundaries`（本編の境目のコマ番号。パートの頭を含む）、`undecided`（未決の黄）、`done`、`parts`（パートの頭とその範囲）、`changes`（押した答え）、`cands`（機械の候補）、`video`（ファイル名・コマ数・fps など）。
コマ番号は動画の最初のコマを0とした番号です。anime-database では `cut_analysis/tools/import_boundary_tool.py` で取り込みます。

## 中身
- `index.html`・`app.js`：画面と処理（WebCodecs で復号し、カット検出の値と TransNetV2 の入力を作る）
- `demux.js`：MKV・WebM（自前）と MP4（mp4box.js）から映像を取り出す
- `tn-worker.js`：TransNetV2 を裏で動かす（onnxruntime-web）
- `model/transnetv2.onnx`：TransNetV2（Souček & Lokoč, 2020。PyTorch 版 transnetv2-pytorch の重みを ONNX に書き出したもの。元の値との差は最大0.03）
- `sw.js`：GitHub Pages で複数スレッドの計算を使うための service worker
- `lib/`：onnxruntime-web（MIT）、mp4box.js（BSD-3-Clause）

H.265（HEVC）の動画は、Chrome とパソコンの組み合わせによっては読めません。そのときは H.264 の MP4 に変換してください。
